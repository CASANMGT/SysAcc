⚙️ Aturan Bank

Saat impor mutasi bank, akun COA diisi otomatis dari kata kunci keterangan. Kata kunci terpanjang menang; aturan berarah lebih spesifik.

➕ Tambah aturan
Contoh: gojek → 5104, biaya adm → 5114, grabfood → 5103, bunga (masuk) → 4102
📋 Aturan tersimpan
⚡ Contoh aturan cepat — klik untuk menambah

🏦 Import Mutasi Bank

CSV BCA / Mandiri / BRI (atau umum: Tanggal, Keterangan, Debit, Kredit). Baris yang cocok nominal+tanggal (±3 hari) otomatis ditandai. Tiap baris direkonsiliasi ke akun COA (disarankan otomatis dari keterangan — bisa diubah).

📚 Daftar Akun

Akun bawaan tidak bisa diubah. Tambah akun sendiri mis. 5120 Beban Iklan — otomatis masuk Laba Rugi & Neraca.

📥 Import COA (tempel dari Excel/CSV)

Satu akun per baris: Kode; Nama Akun; Kategori (pemisah ; TAB atau ,). Kategori: Asset / Liability / Equity / Revenue / Expense. Akun bawaan tidak ditimpa.
